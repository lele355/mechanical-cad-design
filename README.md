# 冲压模具设计与数控编程

凸模 / 凹模结构设计、工艺规程编制与 Mastercam 数控加工程序

## 项目内容

完成冲压件模具的完整设计链条：

```
零件分析 → 模具结构设计 → 三维建模 → 工程图
        → 工艺规程编制 → 工序卡 → 数控编程（Mastercam）→ NC 程序
        → 宇龙仿真验证
```

## 目录结构

```
CAM代码/                凸模 / 凹模各工序 NC 加工程序
  O工序20-凸模.nc ... O工序70-凹模.nc
工序卡/                 数控加工工序卡片（6 份，.docx）
工艺过程卡/             数控加工工艺过程卡片（凸模 / 凹模）
模型及工程图/           凸模、凹模工程图（PDF）
说明书/latex/           三位成员的设计说明书
  main_member1/2/3.tex  各自的 LaTeX 源文件
  compile_all.bat       一键编译脚本
  figures/              装配图、工程图、三维渲染图
答辩PPT.pptx            答辩演示文稿
课程设计题目.pdf         原始任务书
```

## 技术栈

SolidWorks（三维建模 · 工程图）· Mastercam（数控编程）· 宇龙仿真（加工验证）· XeLaTeX（说明书）

## 未纳入版本管理

三维模型（`.sldprt` / `.sldasm` / `.slddrw`）与 Mastercam 工程文件体积大且为二进制专有格式，未上传；工程图已导出为 PDF 保留。

## 复现提示

`说明书/latex/` 下执行 `compile_all.bat` 用 XeLaTeX 编译三份说明书。
